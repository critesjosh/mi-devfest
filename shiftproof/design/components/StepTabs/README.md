# StepTabs

StepTabs switches between the three operations of the demo, in order: 1 Compare, 2 Review, 3 Ask.

The numbers are real: each step needs the one before it. The selected tab is filled with `ink`. Keep exactly three tabs; on a 375px phone the labels stay on one line.

- The consumer provides the selected index and the change handler, and sets `role="tab"` and `aria-selected`.
