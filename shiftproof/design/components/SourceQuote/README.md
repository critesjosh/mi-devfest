# SourceQuote

SourceQuote shows words copied from a source document, with the document and step named above them.

Anything inside a SourceQuote must be an exact copy of the source. The app's own words never go in one. Pair it with a VerifyStamp in the header strip.

- The consumer provides the source name ("Instruction · Step 6" or "Veteran"), the exact text, and the verification result.
- Inside full source panes, highlight quoted spans with `mark` (the `highlight` token).
