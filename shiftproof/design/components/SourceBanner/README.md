# SourceBanner

SourceBanner says where a result came from: live Granite, sample output, or a failed call.

Show it above every model result. Live output gets the quiet source line with the model ID. Sample output always gets the hazard-striped banner, and a failed call adds the reject banner above it. Never hide or soften the sample banner.

- The consumer provides the source (`live`, `sample`), the model ID, and any error text. Banner wording is fixed by the copy contract.
