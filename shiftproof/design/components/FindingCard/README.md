# FindingCard

FindingCard shows one gap between the work instruction and the veteran's notes, with both quotes, why it matters, and the follow-up question.

The type label (OMISSION, AMBIGUITY or CONFLICT) comes first, then the topic. Both quotes sit side by side and stack below 720px. A finding with an unverified quote gets `sp-finding--unverified` and cannot become a card.

- The consumer provides the finding object and, for verified findings, the Expert answer field and the Draft guide card button.
